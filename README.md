## 👨‍💻 About Me

I'm a passionate developer with deep experience in building robust automation platforms, desktop applications, and scalable backend systems. As the Lead Developer at UICommercial.com, I architect and maintain a cutting-edge Electron.js desktop application powered by an ecosystem of 31 automation extensions written in **Python**, **Node.js**, and **Java**.

---

## 🛠️ What I Do

- **Electron.js App Development**  
  Architecting and developing a powerful cross-platform desktop application as the core product at UICommercial.com.

- **Automation Extension Ecosystem**  
  Designing, developing, and integrating 31+ automation extensions using Python, Node.js, and Java.  
    - Bulk printing automation  
    - PDF data scraping  
    - Automated form submission  
    - Advanced web scraping  
    - OCR-powered data extraction from scanned PDFs  
    - Computer vision and image processing with OpenCV  
    - And much more

- **Integrated Data Workflows**  
  Data captured or processed by one automation extension is securely stored in the database and made available for use across other modules. This enables seamless, collaborative workflows and maximizes automation potential.

- **Backend & Database Design**  
  Building scalable, secure APIs and robust database solutions (PostgreSQL, MySQL, MongoDB).

- **Full Lifecycle Ownership**  
  From server maintenance and CI/CD pipelines to frontend oversight and code reviews.
